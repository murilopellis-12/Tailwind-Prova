# REST — Restaurante

## O que é?

Página responsiva de um restaurante, com história, eventos, galeria de fotos e formulário de reserva. Projeto desenvolvido para praticar front-end, baseado em um modelo do [Figma](https://www.figma.com/design/HF2vwbUULhsA0hTXyGJ0Wa/MI81?node-id=0-1).

## Com o que foi feito?

- HTML5
- Tailwind CSS
- JavaScript para interações simples na página

## Como executar?

Abra o arquivo `index.html` no navegador ou utilize a extensão Live Server no VS Code.

É necessário estar conectado à internet para carregar o Tailwind e as fontes. Não precisa instalar dependências com npm.
