# PROVA FRONT-END

Desenvolvimento de uma página estática baseada em um modelo do [FIGMA](https://www.figma.com/design/HF2vwbUULhsA0hTXyGJ0Wa/MI81?node-id=0-1&p=f&t=g8HZADuZ0SYOFFgk-0).


## COMO FOI FEITO:

Foi utilizado HTML5 para estrutura e corpo do nosso site, junto com CSS para dar 
as configurações de estilo e cores.


## COMO EXECUTAR:

- Instale o `.zip` do projeto e descompacte.

    - Você pode rodar clicando diretamente em cima do arquivo `index.html` em seu explorador de arquivos;
    - Você pode abrir a pasta do projeto em uma ide como o VScode e instalar a extensão `Live Server`. Após isso, inicialize o live serve e abre `locahost:5500` em seu navegador.
